Archittos Install

Bash script

An unofficial install script for a clean Arch Linux setup.

Source

About

Run it from the Arch ISO and it installs Arch Linux x86_64 on the disk you choose, with the desktop environment and timezone you pick.

What it does

  • Flags for the EFI disk, the main disk, the desktop environment (kde, gnome, xfce or none) and the timezone
  • --after-boot runs commands once at first login, then deletes itself
  • Reboots by itself when it is finished
Careful. This script is for a clean install without dual boot. It destroys all data on the disk you specify. For dual boot, use the built-in archinstall. The default password is set by the script: change it with passwd.

Requirements

  • The Arch Linux ISO, x86_64
  • An internet connection

Install

  1. Boot the Arch ISO and connect to Wi-Fi with iwctl.
  2. Clone the repository and run ./installscript.sh.
Install
git clone https://github.com/varla-am/archittos-install.git
cd archittos-install
./installscript.sh
