About

SwiftClicker was my first Mac app. It clicks for you with an overlay and a shortcut mode, and it has a small clicker game inside. It went from version 1 to 7 before I moved on to bigger projects like Snowdrop.

What it does

  • Overlay mode and shortcut mode
  • A clicker game: click the button and buy upgrades

Requirements

  • macOS 26.5 Tahoe or newer
  • Accessibility permission, so the app is allowed to click

Install

  1. Download SwiftClicker-7.0.dmg from Releases.
  2. Drag the app into Applications and open it.
  3. Grant Accessibility access in System Settings when asked.
