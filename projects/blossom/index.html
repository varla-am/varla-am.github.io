Blossom

macOS · Swift 1.2

A tiny Spotlight-style launcher: press a hotkey, type a command, and things happen.

DownloadSource

About

Press ⌥ Space, type a word and Blossom runs it. It has no network access of its own, and everything it does is a command you can read in the settings.

What it does

  • Commands: toggle light and dark mode, screensaver, sleep, lock screen, logout, volume and more
  • Web search: search cats opens the results in your browser. Pick Google, DuckDuckGo, Bing, Brave, Ecosia, Startpage, Yandex or your own address
  • Three themes: Aqua, Default (Big Sur to Sequoia) and Liquid Glass
  • Settings can be edited in a friendly form or as JSON

Requirements

  • macOS 14 Sonoma or later (Liquid Glass needs macOS 26 Tahoe)
  • Intel x86_64 or Apple Silicon
  • Xcode 26 or newer to build from source

Install

  1. Download Blossom-v1.2.dmg from Releases.
  2. Drag the app into Applications, or click Install in the dialog.
  3. Open it (right click, Open, or System Settings, Accessibility, Open Anyway).
  4. Press ⌥ Space to launch the line.
