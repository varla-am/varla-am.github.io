CozyBubbles

Claude Code plugin · TypeScript

Puts the messages in Claude Code into rounded, colored bubbles.

Source

About

CozyBubbles changes how a Claude Code session looks: messages from you, the client and Claude live in bubbles, with details you can unfold.

What it does

  • Bubbles for your messages, the client's and Claude's
  • Images: click an image you pasted and it opens in Preview
  • Client details: click the Client header of a bubble to unfold tool calls, their status and output, and the exact duration, model and context
  • Shell and slash commands in bubbles too: yellow for shell, blue for slash commands
  • Code boxes with a Copy button

Requirements

  • Claude Code

Install

  1. In a Claude Code session, run the first command below.
  2. Or, outside a session, run the second one in a terminal.
Claude Code
/plugin install cozy-bubbles --marketplace varla-am/cc-plugin-cozybubbles
Terminal
claude plugin install cozy-bubbles --marketplace varla-am/cc-plugin-cozybubbles
