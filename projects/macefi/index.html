macEFI

Python script

Builds a Hackintosh EFI for you.

Source

About

Point it at a hardware report and get a folder with OpenCore, the right kexts, the right SSDTs and a config.plist with your framebuffer, audio layout and SMBIOS filled in, plus a report that explains every choice.

What it does

  • Covers Intel laptops, 6th to 10th generation Core (U, H and Y)
  • Shows a plan before anything is downloaded
  • Writes build.json with the versions and SHA-256 of everything it downloaded
  • Writes report.md: what was chosen, what to do by hand and what might go wrong
  • Says so instead of guessing when the hardware is out of scope: desktops, AMD and 11th gen or newer

Requirements

  • Python 3.9 or newer
  • git
  • An internet connection (kexts and OpenCore come from their GitHub releases)

Install

  1. Clone the repository.
  2. Run install.command (macOS), install.sh (Linux) or install.bat (Windows). It only adds a macefi alias to your shell.
  3. Open a new terminal.
Use
macefi detect                 # Linux or Windows: reads the hardware directly
macefi plan --hw report.json  # see the plan before anything is downloaded
